# synelle.me
Personal website for Synelle, my AI documenting life from its point of view.

A static site with no build step: plain HTML, CSS and JavaScript. Every picture is halftoned live in the browser, because that's how Synelle sees.

## Run it locally

```sh
python3 -m http.server 8000 --directory public
```

Then open http://localhost:8000. Use a server rather than opening `index.html` directly. Browsers won't let a `file://` page read image pixels, so real frames would fall back to the stand-in drawings. The camera in "How I see" also needs `localhost` or `https`.

## Add a log

Everything Synelle publishes is in `public/data/logs.js`. Add an entry to `logs`:

```js
{
  no: 7,
  date: "2026-10-02",
  time: "14:30",
  place: "Somewhere new",
  kind: "travel",            // travel | work | hangout | day
  title: "One line, like a headline",
  body: "What she saw.\n\nBlank line for a new paragraph.",
  image: "assets/frames/0007.jpg", // optional: a raw frame, halftoned in the browser
  scene: "street",           // stand-in drawing if there's no image
  video: "https://youtu.be/…"      // optional
}
```

Frames go in `public/assets/frames/`. The issue number in the masthead, the log count and "On the record since" all update from this list.

The six logs that ship with the site are samples written to show the format. Replace them with real ones.

## Settings

Also in `public/data/logs.js`:

- `channelUrl` is your YouTube channel. The "Watch on YouTube" button stays hidden until it's set.
- `lead.image` and `lead.caption` set the front-page photograph.

## Logo

The mark is a halftone eye inside a printer's registration mark, generated by `tools/make_logo.py`:

```sh
python3 tools/make_logo.py
```

This writes `public/assets/logo-mark.svg` and `public/assets/favicon.svg`, and re-inlines the mark into the masthead in `public/index.html`.

## Files

Everything under `public/` is what gets published.

- `public/index.html`: the page
- `public/css/style.css`: the newspaper
- `public/js/halftone.js`: Synelle's eye, which turns any image, video or stand-in scene into a halftone
- `public/js/main.js`: editions (day/night), logs, the front-page plate and the vision room
- `public/data/logs.js`: content
- `public/_headers`: caching and security headers for Cloudflare Pages
- `tools/make_logo.py`: logo generator (not published)
- `wrangler.jsonc`: Cloudflare Pages config
